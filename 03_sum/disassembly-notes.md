# C 求和程序的真实反汇编说明

对应 `src/sum.c`。Open Watcom 用 `-0 -ms -od -d2 -bt=dos` 编译成 16 位目标文件，再由 WDIS 反汇编。[机器码清单](results/sum_c.disasm.txt) 保留实际段内地址，[注释版](results/sum_c.annotated.asm) 保留实际指令和常量，只增加中文注释。导出省略 DWARF 调试段和本机路径；`generated.asm` 中的 `.386p/.387` 是 WDIS 默认模板指示，不是执行指令，实际编译选项是 `-0`。

## sum_to_ 与局部变量

`sum_to_` 是 C 函数 `sum_to` 的编译符号。参数 n 按该编译器默认的寄存器约定从 AX 传入，返回值也在 AX。入口先临时保存 AX，再通过 `__STK` 检查栈空间，之后恢复参数，保存 BX/CX/DX/SI/DI/BP，建立 BP 栈帧并分配 8 字节。

| 栈位置 | 含义 | 真实指令位置 |
|---|---|---|
| `[BP-8]` | n 的副本 | 0014h，`MOV -8[BP],AX` |
| `[BP-2]` | total | 0017h 初始化为 0；0032h 累加 |
| `[BP-4]` | i | 001Ch 初始化为 1；0035h 递增 |
| `[BP-6]` | 返回值临时槽 | 003Dh 写入，0040h 取出 |

0024h～002Ch 对应 `i <= n`：取 i 到 AX，再比较 n；`JBE` 表示无符号小于等于时进入循环。002Fh～0032h 对应 `total += i`；0035h 递增 i，0038h 跳回条件。003Ah 取出 total，最终留在 AX。

0043h 开始恢复 SP、BP 和其他被保存的寄存器，004Bh 的 `RET` 返回调用者。关闭优化让变量与栈槽的对应关系更容易观察，也保留了一些临时写回。

## main_、参数与格式串

005Eh 的 `MOV AX,64h` 把十进制 100 放入参数寄存器，0061h 调用 `sum_to_`。0064h 先把返回的 AX 压栈，然后把 `%u\n` 的近指针压栈，0069h 调用 `printf_`。这是可变参数函数的从右到左压栈约定；两个参数共 4 字节，由 006Ch 的 `ADD SP,4` 清理。不能把普通函数的寄存器参数约定与 printf 的可变参数约定混淆。

常量段 `25h 75h 0Ah 00h` 对应 `%u`、换行、C 字符串终止符。C 标准库负责把文本换行转换成 DOS CR/LF。main 返回 0，由 C 运行库启动代码完成退出。

目标文件中的 `CALL` 操作数尚需链接器重定位，清单中出现的 `E8 00 00` 是待修正值。段内偏移也不是最终 EXE 装入后的实地址。机器码清单报告 `No disassembly errors`；`sum_to_` 长 76 字节、`main_` 长 52 字节。
