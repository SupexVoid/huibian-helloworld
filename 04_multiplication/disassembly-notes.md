# C 乘法表程序反汇编分析

这里对照 `src/mult.c` 分析双重循环、乘法和 printf 调用。编译参数为 `wcc -0 -ms -od -d2`，可结合[机器码清单](results/mult_c.disasm.txt)和[中文注释](results/mult_c.annotated.asm)阅读。反汇编的导出方式见[环境与工具](../docs/environment.md#反汇编文件)。

清单中的地址是目标文件的段内偏移。外部 `CALL` 和地址常量还需链接器重定位，零占位值不是最终 EXE 地址。

## C 变量与栈帧

`main_` 的入口先执行 `MOV AX,001Eh`、`CALL __STK`，调用 C 运行库进行栈检查。随后依次保存 BX、CX、DX、SI、DI、BP，执行 `MOV BP,SP`、`SUB SP,8`。在这个栈帧中，`[BP-6]` 对应 row，`[BP-4]` 对应 column，`[BP-2]` 对应 product；`[BP-8]` 是编译器为返回值生成的临时槽。

`L$1` 先调用 `printf_` 输出标题，然后把 row 初始化为 9。格式串近指针压栈占 2 字节，调用后用 `ADD SP,2` 清理。标题在常量段的 `L$14`，其中末尾 `0Ah,00h` 分别是 C 的换行和字符串终止符。DOS C 文本输出在运行时转换 CR/LF。

## 两层循环及乘法

| C 逻辑 | 标签/代码段地址 | 指令含义 |
|---|---|---|
| `row != 0` | `L$2` / 0024h | 比较 `[BP-6]` 与 0；为零则转到 `L$11` |
| `column = 1` | `L$3` / 002Dh | 向 `[BP-4]` 写入 1 |
| `column <= row` | `L$4` / 0032h | AX 读取列因子后比较行因子；`JBE` 实现无符号小于等于 |
| `product = row * column` | `L$5` / 003Dh | `MOV AX,[BP-6]`；0040h 的 `F7 66 FC` 对应 `MUL word ptr [BP-4]` |
| `++column` | `L$8` / 0074h | `INC word ptr [BP-4]` 后跳回 `L$4` |
| `--row` | `L$10` / 0083h | `ADD word ptr [BP-6],0FFFFh` 后跳回 `L$2` |

C 的无符号 16 位乘法使用 AX 与内存中的列因子，结果为 DX:AX。编译器把 AX 存到 product；本题最大乘积 81，所以 DX 必为 0，没有丢失有效高位。手写汇编的 `MUL CL` 则是 8 位乘法，结果为 AX；两者的操作数宽度和隐含结果寄存器不同。

由于关闭优化，反汇编中存在条件跳转后接近跳转、冗余中间标签和读回临时变量等代码。这些指令可以用来观察未优化的 C 程序如何实现循环。

## printf、空格和返回

0046h 起，编译器逆序压入 product、column、row、`L$15` 格式串地址，然后在 0056h 调用 `printf_`。四个参数各占 2 字节，0059h 的 `ADD SP,8` 清理参数。`L$15` 的内容是 `%u*%u=%u`，`%u` 与三个 `unsigned int` 变量匹配。

005Ch 比较 column 与 row：相等时经 `L$6` 跳过空格输出，否则转入 `L$7`，用 `L$16` 的两个空格调用 `printf_`。`L$9` 用 `L$17` 输出换行。因此每行最后一项没有尾随空格。

`L$11` 把 0 经 `[BP-8]` 放入 AX。`L$12` 执行 `MOV SP,BP` 释放局部变量，再逆序弹出 BP、DI、SI、DX、CX、BX；0099h 的 `RET` 返回 C 运行库启动代码，随后由运行库退出 DOS。它与手写汇编 main 中直接执行 `INT 21h/AH=4Ch` 的退出路径不同。

WDIS 文件开头的 `.387`、`.386p` 是反汇编器默认生成的模板头，不是 `main_` 执行的机器指令，也不表示把 C 编译成了 386 程序。编译参数是 `-0`；`_TEXT` 段为 `USE16`，长 009Ah（154）字节，所列主函数指令均为 8086 可用指令。DWARF 调试数据不属于运行时代码，已从反汇编清单中省略。

## 汇编版的栈使用补充

汇编版的调用链为 `main → PrintTerm → PrintUnsigned → PutChar`。打印两位数的首位时，返回地址和保存的寄存器共占 26 字节，另有一个尚未输出的余数占 2 字节，共 28 字节。执行 `INT 21h` 还会压入 FLAGS、CS、IP，共 6 字节，所以这部分可见栈用量为 34 字节。这个计算不包含 DOS 内部实现可能使用的其他栈空间。
